1.2 国内外研究现状
智能制造的核心目标之一，是将长期依赖工艺专家个人经验的装配决策，转化为可由机器自主完成、且过程可信、结果可追溯的工艺规划过程。围绕这一目标，本文将从以下四条彼此衔接的线索展开综述：装配工艺知识的组织与表达（知识底座）、装配序列的自主生成（决策核心）、装配资源与动作的规划（执行落地），以及贯通上述三者的知识驱动装配系统集成。前三条线索分别对应本文的三个核心研究模块，第四条线索则旨在揭示三者集成所面临的共性缺口与研究机遇。

1.2.1 装配工艺知识的组织与表达
装配工艺知识天然分散于工艺文档、工程图像与三维模型之中，呈现多源、异构、语义隐含的特点。如何将其组织为可复用、可推理、可追溯的形式，是实现装配决策自动化的前提。知识图谱与本体因能显式承载概念、关系与约束，成为该领域的主流信息载体[1]。张栋豪等系统综述了知识图谱在智能制造中的应用现状，指出其相较传统计算机辅助工艺规划在多模态知识存储与可解释推理上的显著优势[1]；Xiao等则针对知识图谱驱动的制造工艺规划给出了状态综述，确立了过程知识图谱作为传统制造向智能制造转型关键技术的地位[2]。

在构建方法上，研究脉络经历了由人工/规则建模向数据与大模型驱动的演进。早期工作多以预定义本体配合规则抽取实现工艺知识图谱构建，如李秀玲等面向工艺重用提出的工艺知识图谱构建方法[3]；近年来，随着大语言模型语义理解能力的成熟，LLM辅助的自动化构建成为新趋势，胡志强等基于多源异构数据构建了风机多模态装配工艺知识图谱[4]，赖赞有等则提出了基于大模型的船舶装配工艺知识图谱构建方法[5]。与此同时，知识图谱的作用也从“存储与检索”向“推理与生成”延伸，杨伟凯等提出面向知识图谱的工艺知识推理方法[6]，刘鸣飞等进一步研究了融合几何与工艺语义的装配工艺重用方法[7]。在英文文献中，多智能体协同被引入知识图谱的构建侧：Pu等提出多智能体大模型框架MA-APKG，用于构建航空装配工艺知识图谱[8]；Lu与Wang提出的KARMA框架则以多智能体分工实现知识图谱的增量富集[9]。

然而，现有装配工艺知识图谱大多服务于知识检索、问答与工艺重用[4, 5, 7]，其本体设计普遍未为下游的序列生成与执行规划预留语义接口；而将多智能体投入构建侧的工作[8, 9]，其产物仍是静态知识库，不涉及运行时的几何与视觉证据，也不直接产出装配决策。如何构建一个既能保证抽取准确性与可追溯性、又能同时承载工艺语义与资源语义、为下游决策提供统一先验的装配工艺知识图谱，仍有待深入研究。

1.2.2 装配序列的自主生成
装配序列规划是连接产品设计与制造执行的关键工艺决策环节。传统方法可分为三类：基于几何推理的方法通过分析可分离性与干涉关系判定可行顺序，可解释性强但面临组合爆炸问题[10]；图论方法将装配约束表示为优先关系并求解拓扑序；元启发式优化方法以干涉矩阵与代价权重为输入搜索近优顺序，其专家经验被压缩为目标函数与权重。近年来，学习类方法成为热点，Shu等以图注意力网络结合强化学习实现了从子装配到整装配的序列规划[11]。引入知识图谱以承载装配语义先验是另一条重要路线：蒋明杰等基于本体构建知识图谱，并以带反馈的图规划算法从中求解直升机部件的装配序列，利用知识图谱提供的优先关系有效压缩了搜索空间[12]。

在大模型方向上，与本文最接近的工作中，Xie等提出以多智能体协作结合知识图谱快速生成机加工艺路线，并明确指出多智能体与知识图谱的结合可有效降低大模型在工业场景中的幻觉[13]；在装配侧，AssemMate从装配文档与三维模型构建装配知识图谱并以图结构注入大模型，支持装配问答与任务规划[14]。

上述工作共同推进了装配序列自主生成的能力，但其局限相互独立而又彼此叠加：几何、优化与多数学习方法的输出止于零件顺序与方向，工艺语义贫乏[10, 11]；基于知识图谱的序列规划虽引入了语义先验，但仍以知识图谱作为静态的优先约束进行图搜索，缺乏对先验的运行时核验，也不产出配合类型、姿态、夹持等成套工艺语义，更无逐步证据溯源[12]；而大模型方法虽以外部知识缓解了单轮幻觉，其对象多为机加工艺路线或装配问答，尚未落到“装配序列 + 成套工艺语义 + 逐步证据溯源”的统一输出[13, 14]。这正是本文模块B所要填补的缺口。

1.2.3 装配资源与动作的规划
生成装配序列之后，需进一步结合具体装配系统，将工艺意图实例化为可执行作业。这一环节包括工艺装备选型、机器人末端执行器选择与夹具设计选择三个相互关联的子问题。

在工艺装备选型方面，主流范式是将其建模为多准则决策问题。Li等提出融合模糊DEMATEL、熵权与VIKOR的混合MCDM模型用于机床选型[15]，Tran等采用模糊AHP-TOPSIS进行工业机器人选型[16]，Hagag等则系统综述了制造领域设备选型的MCDM方法谱系[17]。为突破静态选型的局限，近年研究开始将选型与规划耦合并引入知识：Yang等在可重构装配系统中将设备选型与序列规划纳入同一多目标优化模型[18]，Smedberg等提出知识驱动的多目标优化用于可重构制造系统配置[19]，Zhang等针对云制造与社会化制造场景研究了知识使能的分布式制造资源动态配置[20, 21]。

在夹持器选择与抓取规划方面，研究正从面向通用拾取的几何质量度量，转向任务导向与语义知识驱动。Xu等提出面向装配任务的结构化夹持器选择与设计方法[22]，Zhao等以级联网络预测面向装配的任务导向抓取[23]；进一步地，Tang等提出GraspGPT，利用大语言模型的开放语义知识实现任务导向抓取[24]，并扩展为基于基础模型的FoundationGrasp[25]。国内相关研究则多集中于视觉抓取检测综述[26]，面向装配的夹持器选型专题相对稀缺。

在夹具设计与选择方面，方法学由几何力学数值优化[27]，经数据驱动代理模型[28, 29]，向知识驱动演进。Boonsuk提出基于知识重用的计算机辅助夹具设计框架[30]，张发平等提出基于知识本体与知识组件的夹具结构智能设计方法[31]；2024年起，Meng等将知识图谱显式用于飞机壁板可重构柔性夹具的配置级智能设计[32]。

总体而言，装配资源与动作规划的三个子问题虽各自取得进展，但呈现两个共性局限：其一，三者彼此割裂，设备、夹持器与夹具的选择多被作为独立问题处理，缺乏统一的上游工艺语义驱动；其二，普遍依赖人工输入工艺意图或专家主观赋权，MCDM方法的候选集需人工枚举、权重靠专家给定[15-17]，知识驱动方法所用的“知识”多为浅层案例库或设计规则[30, 31]，难以从产品设计信息自动、可追溯地推导资源选择依据。如何以装配序列所携带的成套工艺语义为驱动，实现设备、夹持器、夹具的级联协同选择，并使每一选择可回溯至工艺约束证据，是本文模块C的研究重点。

1.2.4 大模型驱动的机器人装配规划与知识驱动系统集成
作为模块B向模块C过渡的方法学桥梁，大模型驱动的机器人任务与动作规划近年发展迅速。早期工作令大模型直接充当规划器，如Code-as-Policies[33]、ProgPrompt[34]；SayCan则以可供性价值函数将语言指令接地于机器人技能[35]。研究者很快意识到大模型擅长语义分解却缺乏物理可行性保障，进而发展出“大模型 + 任务运动规划 + 失败反馈”的闭环范式，如LLM3[36]、AutoTAMP[37]，以及将本体与图结构注入规划以提供领域约束的方向[38]。国内方面，秦龙等提出基于大语言模型的复杂任务自主规划框架[39]，中国科学院沈阳自动化研究所团队则研究了面向可靠规划的轨迹引导式领域修复[40]。这一领域的共识是：大模型须由价值函数、失败推理或符号约束加以“接地”，方能保证可行性；但真正面向“装配设备选型 + 夹持器/夹具选择”的大模型工作仍属空白。

在系统集成层面，数字孪生作为虚实闭环底座，已由概念综述[41, 42]发展为系统设计方法论[43, 44]与执行级落地应用，如Bilberg与Malik的数字孪生驱动人机协作装配[45]，以及国内宋轶民等基于数字孪生的并联机器人筒段装配系统[46]。最新方向是将“知识”显式注入数字孪生——由知识驱动制造单元[47]、认知数字孪生[48]发展至数字孪生与知识图谱的融合[49]；在装配工艺设计侧，Liu等提出数字孪生驱动的复杂产品智能装配工艺设计框架[50]，郭飞燕等综述了数字孪生驱动装配工艺设计的现状与关键实现技术[51]。尤为值得关注的是，清华大学团队提出面向跨品类产品的可重构柔性装配技术，确立了包含产品、工艺、资源、知识、决策的“五要素”装配模型，并给出设计-配置-运行三阶段重构实现体系[52, 53]。该模型将知识、资源与决策置于装配模型中心，与本文A→B→C的三模块结构高度同构，是最具参考价值的近期框架；但其论述侧重于体系与装配语言层面[54]，设备—夹持器—夹具的具体选型决策算法及其证据可追溯机制尚未形式化。

综上，知识驱动装配系统的研究虽已勾勒出“知识—工艺—执行”集成的愿景，却普遍止于框架或语言层面，缺少一个以可溯源知识图谱为统一底座、贯通装配序列生成与资源动作规划、且实现全链路证据可追溯的细粒度集成方法。

1.2.5 研究现状小结与本文切入点
综合上述四条线索可见（图1.x）：装配工艺知识的组织已较为成熟，但少有为下游决策专门设计、兼容工艺与资源语义的本体；装配序列生成或语义贫乏、或缺乏运行时证据核验与溯源；装配资源规划的三个子问题彼此割裂、依赖人工工艺意图输入；而系统集成层面缺少以可溯源知识为底座、贯穿设计到执行的统一框架。这四点缺口在逻辑上层层递进，共同指向本文的总体研究命题：以可溯源装配工艺知识图谱为统一底座（模块A），以知识图谱先验结合多智能体证据闭环生成带成套工艺语义的装配序列（模块B），再以序列所携带的工艺语义级联驱动设备、夹持器与夹具的协同选择及装配动作规划（模块C），从而实现“设计—工艺—执行”全链路证据可追溯的智能装配决策方法。其中，模块B已在本文小论文中实现并验证，模块A与模块C构成本大论文的核心贡献。
