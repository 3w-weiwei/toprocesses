# 大论文五章框架建议

## 0. 建议题目

**面向固定双臂柔性装配单元的可追溯装配工艺知识复用与工步级决策方法研究**

备选题目：

1. **面向机械产品装配工步规划的知识图谱与多智能体决策方法研究**
2. **基于可追溯工艺知识复用的机械产品装配序列与资源决策方法研究**
3. **面向柔性装配单元的装配工艺知识复用、序列生成与工步资源决策方法研究**

建议采用第一个题目。它把研究边界说清楚：不是设计整条产线，不是完整机器人轨迹规划，而是面向一个固定双臂柔性装配单元，把工厂已有装配经验转化为可复用知识，并生成可追溯的工步级决策方案。

## 1. 总体研究定位

### 1.1 核心问题

机械产品装配工艺知识大量存在于工艺文件、自动化装配案例、设备说明、三维模型和工程经验中。传统装配规划往往依赖工艺人员从零判断装配顺序、工具、夹持器、夹具与特殊工艺资源，导致知识难复用、决策依据难追溯、柔性装配单元重构效率低。

本文拟解决的问题是：

> 如何将已有工厂自动化装配案例中的工艺经验转化为可复用、可追溯的装配知识，并在固定双臂柔性装配单元约束下生成带工艺语义的装配序列和工步级资源决策方案？

### 1.2 建议技术边界

本文建议采用**固定双臂装配单元**作为系统边界：

- 两台 Franka 机械臂基座位置、工作台位置、工具/夹持器存放区、夹具安装区给定；
- 不研究整条产线或多个装配单元之间的选择；
- 不研究工作站布局优化；
- 不研究完整轨迹生成和碰撞自由运动规划；
- 重点研究工艺知识复用、装配序列推导、工步模板匹配、资源候选生成、可行性过滤与多准则排序。

该边界可避免问题膨胀到可重构制造系统配置、双臂布局优化、夹具结构详细设计和机器人运动规划，同时保留足够的工程价值。

### 1.3 总体技术路线

```text
工厂自动化装配案例 / 工艺文档 / 图像 / STEP
        ↓
装配工艺知识建模与图谱构建
        ↓
KG 先验 + 几何/视觉证据 + 多智能体证据闭环
        ↓
带工艺语义与证据引用的装配序列
        ↓
工步模板匹配 + 资源库约束过滤 + 多准则决策
        ↓
固定双臂柔性装配单元下的工步级方案
```

## 第 1 章 绪论

### 1.1 研究背景与意义

建议从三个层次展开：

1. 智能制造与柔性装配对装配工艺自动决策提出需求；
2. 机械产品装配知识分散、隐性、经验化，导致知识复用困难；
3. 大模型和多智能体带来新的规划能力，但必须受到知识、几何、资源和证据约束。

需要强调本文不是“用大模型替代工艺员”，而是构建一种**知识可复用、决策可追溯、人机协同可校核**的工步级规划方法。

### 1.2 国内外研究现状

建议分为四条线索：

1. 装配工艺知识表示与知识图谱；
2. 装配序列规划与知识驱动序列生成；
3. 装配资源、夹持器、夹具与工步规划；
4. 大模型/多智能体在制造和机器人规划中的应用。

该部分可参考 `docs/outline/国内外研究现状整理.md`。

### 1.3 现有研究不足

建议凝练为四点：

1. 现有装配工艺知识图谱多服务于检索、问答或工艺管理，较少面向下游序列生成和工步资源决策设计统一语义接口；
2. 传统装配序列规划多输出顺序、方向或位姿，缺少配合类型、工艺原语、夹持面、工装需求和证据来源等工步级语义；
3. 装配资源选择、夹持器选择、夹具选择往往作为独立问题处理，缺少由上游工艺语义统一驱动的级联决策机制；
4. LLM/Agent 方法具备语义分解和工具调用能力，但若缺少本体、约束、证据准入和工程评价模型，容易被专家认为理论依据不足。

### 1.4 研究内容

本文建议设置三个主要研究内容：

1. 面向工步规划的可追溯装配工艺知识建模与复用；
2. KG 先验与多智能体证据闭环的装配序列生成；
3. 面向固定双臂柔性装配单元的工步级资源决策。

### 1.5 创新点

建议写为：

1. 提出面向工步规划的产品-工艺-资源-证据一体化知识表示模型，将自动化装配案例中的工艺经验组织为可检索、可推理、可追溯的知识图谱；
2. 提出知识图谱先验与多智能体证据闭环相结合的装配序列生成方法，使装配序列从“零件顺序”扩展为“工艺语义 + 证据链”的步骤级决策结果；
3. 提出面向固定双臂柔性装配单元的工步级资源决策方法，通过工步模板、资源库约束过滤和多准则评价，将装配语义映射为工具、夹持器、夹具和特殊工艺资源方案；
4. 构建锂电池模组装配案例验证流程，验证工厂装配经验向柔性装配单元迁移复用的可行性。

### 1.6 本章小结

本章应收束到本文研究主线：以可追溯知识复用为基础，以带工艺语义的装配序列为中间表示，以固定双臂装配单元下的工步级资源决策为落地对象。

## 第 2 章 面向工步规划的可追溯装配工艺知识建模与复用

### 2.1 本章目标

本章解决“知识如何复用”的问题。它不是简单地让 LLM 从文档中抽取知识，而是建立一个能支撑后续序列生成和工步决策的知识底座。

### 2.2 主流方法与本文选择

本章可吸收的主流方法包括：

1. **本体建模**：定义装配对象、工艺动作、资源、参数、约束和证据的概念体系；
2. **知识图谱**：以实体-关系-属性形式组织多源工艺知识；
3. **案例推理**：将已有自动化装配案例作为可复用经验单元；
4. **规则推理**：将“螺纹紧固需要电批”“胶接需要点胶工具和固化约束”等经验写成规则或约束；
5. **来源追踪**：每条知识绑定文档块、图像、STEP 组件或人工标注来源。

本文不应把 LLM 抽取写成本章唯一方法。LLM 只是辅助构建工具，理论主体应是本体、图谱、案例库和规则约束。

### 2.3 产品-工艺-资源-证据模型

建议建立扩展 PPR 模型：

```text
Product: 产品、部件、零件、几何特征、配合面
Process: 工艺步骤、工艺原语、装配顺序、参数、质量要求
Resource: 机器人、夹持器、工具、夹具、工作台、特殊工艺设备
Evidence: 文档块、图像、STEP 组件、历史案例、专家标注
```

可以形式化为：

```text
K = (V, R, A, Sigma)
V: 实体集合
R: 关系集合
A: 属性与约束集合
Sigma: 来源映射
```

### 2.4 自动化装配案例表示

你已有的工厂自动化装配案例是本章最有价值的数据来源。建议把每个案例表示为：

```text
Case = {
  产品对象,
  零件/子装配结构,
  工艺步骤序列,
  工艺原语,
  使用工具/夹具/设备,
  关键参数,
  质量约束,
  适用条件,
  来源证据
}
```

案例复用机制：

1. 根据产品结构和工艺原语检索相似案例；
2. 复用相似案例中的工步模板、资源选择和参数范围；
3. 对不满足当前几何/资源约束的部分进行修正或标记缺失；
4. 将复用结果作为第 3 章和第 4 章的先验。

### 2.5 工步模板库

建议建立若干可复用工步模板：

| 工步模板 | 典型输入 | 典型资源 | 关键约束 |
|---|---|---|---|
| 放置/堆叠 | 零件、基准面、放置方向 | 夹持器、定位夹具 | 可达性、支撑面、姿态 |
| 插装 | 轴孔/导向面/插入方向 | 夹持器、导向夹具 | 插入轴、间隙、碰撞 |
| 螺纹紧固 | 螺钉、孔位、扭矩 | 电批、批头、定位夹具 | 扭矩、轴向可达、孔位 |
| 涂胶/点胶 | 胶路、胶量、固化条件 | 点胶工具/点胶站 | 路径、胶量、固化时间 |
| 压紧/压装 | 压紧面、力/位移要求 | 压紧机构/压机 | 力、行程、支撑 |
| 焊接 | 焊点/焊缝、材料 | 激光焊接站/焊接工具 | 安全、热影响、设备能力 |
| 检测 | 检测对象、指标 | 相机、传感器、测试设备 | 视野、精度、阈值 |

特殊工艺如激光焊接、热压、电性能测试不必强行由双臂执行，可作为 `SpecialTool` 或 `ExternalProcessStation` 建模。

### 2.6 知识复用输出

本章输出：

1. 装配工艺本体；
2. 可追溯知识图谱；
3. 自动化装配案例库；
4. 工步模板库；
5. 规则/约束集合；
6. 面向后续章节的知识查询接口。

### 2.7 本章小结

本章应强调：知识复用不是简单 RAG 检索，而是“案例 + 本体 + 图谱 + 规则 + 来源证据”的组合。其输出为第 3 章提供装配语义先验，为第 4 章提供资源能力和工步模板依据。

## 第 3 章 知识图谱先验与多智能体证据闭环的装配序列生成

### 3.1 本章目标

本章承接你的小论文工作，解决“如何从产品结构、工艺知识和运行时证据生成装配序列”的问题。

### 3.2 主流方法与本文选择

可对比的主流方法：

1. 几何推理与拆卸反推；
2. 优先关系图与拓扑排序；
3. 遗传算法、蚁群、粒子群等元启发式优化；
4. 强化学习、图神经网络等学习方法；
5. KG 辅助规划；
6. LLM/Agent 辅助工艺规划。

本文选择：

```text
KG 工艺先验 + STEP 几何/视觉证据 + 多智能体取证 + 约束图拓扑排序
```

这样既有智能体灵活性，又有约束图、证据准入和拓扑排序作为理论支撑。

### 3.3 问题形式化

输入：

```text
G_cad: STEP 解析得到的装配树、几何关系、候选接触、方向候选
K: 第 2 章构建的可追溯装配工艺知识图谱
V: 按需获取的视觉证据
```

输出：

```text
S = <s_1, ..., s_n>
s_i = (p_i, omega_i, E_i)
omega_i = (prim, role, F, Theta, Gamma)
```

其中：

- `prim` 为工艺原语；
- `role` 为基座件/移动件角色；
- `F` 为配合面或作用面；
- `Theta` 为姿态、方向或接近约束；
- `Gamma` 为工具、夹持或工装需求；
- `E_i` 为证据集合。

### 3.4 多智能体角色

建议采用四类角色：

| 智能体/角色 | 作用 | 理论支撑 |
|---|---|---|
| APO | 全局编排、约束图构建、拓扑排序 | 约束图、证据准入、拓扑排序 |
| KRA | 检索 KG 与案例知识 | 本体查询、图检索、来源追踪 |
| PFA | 分析零件特征与候选夹持/配合面 | STEP 几何、视觉证据 |
| VES | 获取或选择视觉证据 | 证据分层、图像可复核 |

需要强调：Agent 不直接“拍脑袋生成序列”，而是在约束图和证据规则下执行取证、检索和候选生成。

### 3.5 证据分层与准入规则

建议保留你已有的证据分层：

| 证据层 | 来源 | 作用 |
|---|---|---|
| L0 | 文件和工具元数据 | 证据定位 |
| L1 | STEP 几何事实 | 几何存在、邻接、方向候选 |
| L2 | 视觉制品 | 可复核接触、遮挡、方向 |
| L3 | 启发式候选 | 提出待验证假设 |
| L4 | 智能体推断 | 只能作为待验证结论 |

核心原则：

```text
L4 不能作为自身证据；
仅有启发式候选不能达阈；
连接工艺、材料、扭矩、焊接、胶接必须有 KG/文档/案例证据；
证据不足时登记缺失项，而不是强行补全。
```

### 3.6 约束图构建与序列推导

约束边类型可包括：

- 空间前置；
- 工艺前置；
- 定位前置；
- 阻挡前置；
- 紧固前置；
- 封闭前置；
- 工装前置；
- 特殊工艺前置。

序列生成过程：

1. 从 KG 和案例库生成候选优先关系；
2. 从 STEP 几何和视觉证据验证候选关系；
3. 将达阈关系写入约束图；
4. 检测环路和矛盾；
5. 拓扑排序生成装配序列；
6. 为每一步填充工艺语义字段和证据引用。

### 3.7 实验设计

建议至少设置：

1. 与无 KG 的单智能体规划对比；
2. 与仅 KG 静态优先关系规划对比；
3. 去除 VES 的消融；
4. 去除证据准入规则的消融；
5. 与专家序列/工厂案例序列对比。

评价指标：

- 序列优先关系准确率；
- 工艺原语准确率；
- 配合面/夹持面字段准确率；
- 证据可追溯率；
- 证据不足识别率；
- 专家评分；
- 人工修正量。

### 3.8 本章小结

本章应强调：本文将小论文已有成果定位为大论文的决策核心。它把第 2 章的知识复用结果转化为带工艺语义和证据链的装配序列，并为第 4 章工步资源决策提供结构化输入。

## 第 4 章 面向固定双臂柔性装配单元的工步级资源决策

### 4.1 本章目标

本章解决“装配序列如何落到工步层面”的问题。它不是完整机器人轨迹规划，而是根据第 3 章输出的工艺语义，生成固定双臂装配单元下的资源选择和工步方案。

### 4.2 双臂装配单元边界

建议固定以下条件：

- 两台 Franka 机械臂位置固定；
- 中央装配工作台固定；
- 工具架、夹持器库、夹具安装区给定；
- 可选资源包括夹持器、工具、夹具、特殊工艺设备；
- 不优化机器人基座位置和工作站布局。

这部分可以作为实验平台假设，而非本文主要贡献。否则会扩展成双臂布局优化和可重构装配系统配置问题，难度过大。

### 4.3 主流方法与本文选择

可参考主流方法：

1. 可重构装配系统中的设备选择与序列规划联合优化；
2. MCDM 方法，如 AHP、TOPSIS、VIKOR、熵权法；
3. 知识驱动资源配置；
4. 夹持器选择与任务导向抓取；
5. 夹具知识重用与可重构夹具设计；
6. LLM/TAMP 的任务分解和失败反馈机制。

本文建议选择：

```text
工步模板匹配 + 资源硬约束过滤 + 案例相似度复用 + 多准则排序
```

Agent 只作为查询和编排层，不作为唯一决策依据。

### 4.4 资源库建模

资源库建议分为：

| 类型 | 示例 | 关键属性 |
|---|---|---|
| 机器人 | Franka 左臂、Franka 右臂 | 负载、工作空间、末端接口 |
| 夹持器 | 两指夹爪、真空吸盘、软夹爪 | 夹持范围、负载、接触类型 |
| 工具 | 电批、点胶头、压紧工具、检测相机 | 工艺能力、参数范围、接口 |
| 夹具 | 定位夹具、支撑夹具、压紧夹具 | 定位基准、支撑面、夹紧方式 |
| 特殊设备 | 激光焊接、热压、测试设备 | 工艺类型、安全约束、外部调用 |

### 4.5 从工艺语义到工步模板

第 3 章输出的 `omega_i` 可映射到工步模板：

| `prim` | 工步模板 | 资源需求 |
|---|---|---|
| 堆叠/放置 | 抓取-搬运-定位-释放 | 夹持器、定位夹具 |
| 插装 | 抓取-对准-插入-确认 | 夹持器、导向夹具 |
| 螺纹紧固 | 定位-取螺钉-拧紧-扭矩确认 | 电批、批头、定位夹具 |
| 涂胶/点胶 | 定位-点胶-等待/固化 | 点胶工具、轨迹模板 |
| 压紧/压装 | 定位-施压-保持-释放 | 压紧工具/压机、支撑夹具 |
| 焊接 | 定位-夹紧-调用焊接设备-检测 | 焊接站、夹紧夹具 |
| 检测 | 定位-采集-判定 | 相机/传感器 |

### 4.6 候选资源生成

对于每个工步：

```text
候选资源 = KG 查询结果 ∪ 相似案例资源 ∪ 工步模板默认资源
```

候选来源必须保留证据：

- 来源于历史案例；
- 来源于工艺规则；
- 来源于设备能力库；
- 来源于专家配置；
- 来源于 Agent 推断但待复核。

### 4.7 硬约束过滤

先筛掉不可行资源：

```text
R_i^F = {r in R | capability(r) satisfies requirement(omega_i)}
```

约束可包括：

- 负载约束；
- 夹持范围；
- 夹持面兼容性；
- 工艺能力；
- 可达性；
- 工具接口；
- 夹具定位基准；
- 安全约束；
- 特殊工艺设备是否可用。

### 4.8 多准则排序

建议采用 TOPSIS 或 AHP-TOPSIS，不要同时堆太多方法。

评分指标可包括：

| 指标 | 含义 |
|---|---|
| 工艺匹配度 | 工具/夹具是否满足工艺原语 |
| 几何兼容性 | 是否匹配夹持面、配合面、零件尺寸 |
| 可达性 | 固定双臂单元内是否可达 |
| 稳定性 | 夹持/定位是否稳定 |
| 换装成本 | 是否需要更换夹具/工具 |
| 案例相似度 | 是否在历史案例中成功使用 |
| 证据置信度 | 资源选择依据是否可追溯 |

总评分可写为：

```text
Score(r) = w1 M_process + w2 M_geometry + w3 M_reach
         + w4 M_stability + w5 M_changeover
         + w6 M_case + w7 M_evidence
```

### 4.9 工步级方案输出

每个工步输出：

```text
StepPlan_i = {
  工步模板,
  主操作臂,
  辅助臂,
  夹持器,
  工具,
  夹具状态,
  特殊工艺资源,
  前置条件,
  后置条件,
  证据来源,
  不可执行原因
}
```

特殊工艺处理原则：

- 能由机器人直接执行的，输出工具和动作模板；
- 需要专用工具的，输出专用工具资源；
- 需要外部设备的，输出外部工艺站调用需求；
- 缺少工艺参数的，进入缺失项报告。

### 4.10 实验设计

建议验证：

1. 工步模板匹配准确率；
2. 工具/夹持器/夹具推荐准确率；
3. 资源选择与工厂案例一致率；
4. 特殊工艺识别正确率；
5. 不可执行项识别率；
6. 专家评分；
7. 与纯 Agent 选择、无案例复用、无约束过滤方法对比。

### 4.11 本章小结

本章应强调：本文将装配序列输出进一步落到固定双臂柔性装配单元的工步级资源决策，但不声称完成完整运动规划和真实夹具设计。其价值在于把工厂工艺经验、资源能力与步骤级证据贯通起来。

## 第 5 章 原型系统实现与案例验证

### 5.1 本章目标

本章通过锂电池模组装配案例验证第 2-4 章方法的可行性。

### 5.2 案例选择合理性

锂电池模组适合作为主要案例，因为它同时包含：

- 自动化装配案例数据；
- 多种工具、夹具和特殊设备；
- 质量与安全约束。

需要注意：锂电池是案例，不是本文方法的唯一适用对象。论文中可补充一个小型机械装配体作为附加验证，以增强泛化说服力。

### 5.9 本章小结

本章应证明：本文方法能把工厂已有自动化装配经验转化为可复用知识，并在固定柔性装配单元中生成可追溯、可校核的工步级方案。

## 最终建议

五章之间的逻辑应保持为：

```text
第 1 章：提出问题与研究路线
第 2 章：知识如何表达和复用
第 3 章：如何生成带工艺语义的装配序列
第 4 章：如何把工艺语义落到固定双臂单元的工步资源决策
第 5 章：通过锂电池模组案例验证
```

最重要的边界表述：

> 本文研究对象不是整条装配产线配置，也不是完整机器人运动规划，而是面向固定双臂柔性装配单元的工步级装配决策支持。本文通过知识图谱、案例复用、约束图、证据准入和多准则决策，将已有工厂装配经验转化为可追溯、可复用、可校核的工步规划依据。
