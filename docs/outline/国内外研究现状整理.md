# 国内外研究现状整理

## 0. 调研目标

本文件服务于大论文第 1 章“国内外研究现状”。重点围绕本文拟定主线：

> 可追溯装配工艺知识复用 → 装配序列生成 → 固定双臂柔性装配单元下的工步级资源决策。

本文不把研究现状写成“大模型/Agent 应用综述”，而是按机械装配工艺规划的技术链条组织：知识表达、序列规划、资源与工步决策、双臂装配单元、特殊工艺处理。

## 1. 装配工艺知识表示与知识图谱

### 1.1 主流研究脉络

装配工艺知识具有多源、异构、隐性和经验化特征，传统数据库或文档管理难以表达工艺对象、工艺动作、资源、参数和约束之间的语义关系。因此，研究逐渐从规则库、案例库、本体模型发展到知识图谱。

主流方法包括：

1. **规则库与案例库**：通过 if-then 规则或历史案例复用装配经验，适合格式稳定、对象明确的场景，但扩展性和跨产品复用能力有限；
2. **本体建模**：定义产品、工艺、资源、参数、约束等概念和关系，支持语义一致性与规则推理；
3. **知识图谱**：以实体、关系、属性表达多源知识，支持检索、推理、问答和下游规划；
4. **LLM 辅助知识抽取**：利用大模型从非结构化工艺文本、图像和多模态资料中抽取知识，但需要本体约束、证据定位和人工校核抑制幻觉。

### 1.2 代表性研究

Xiao 等在 Journal of Manufacturing Systems 上发表的综述系统梳理了知识图谱驱动制造工艺规划的研究现状，指出过程知识图谱可支撑制造工艺知识的表示、抽取、构建、精炼、验证和过程生成，是传统 CAPP 向智能制造转型的重要支撑。[Xiao et al., 2023](https://scholar.xjtu.edu.cn/en/publications/knowledge-graph-based-manufacturing-process-planning-a-state-of-t/)

MA-APKG 提出面向复杂航空产品装配工艺知识图谱的多智能体 LLM 构建方法。该文将装配过程知识划分为产品信息层、工艺知识层、工具设备资源层、历史案例层和工艺决策规则层，并使用本体约束、多智能体抽取和动态更新机制保证语义一致性。该工作说明：在复杂装配工艺场景中，工具、设备、历史案例和决策规则不应是附属信息，而应纳入知识模型本身。该点对本文第 2 章和第 4 章具有直接参考价值。

国内方面，已有研究围绕智能制造知识图谱综述、工艺知识图谱构建、多源异构装配工艺知识图谱、船舶或风机装配工艺 KG 构建等方向展开。这类工作说明中文机械制造领域已经认可“知识图谱 + 工艺知识复用”的研究价值，但多数工作仍停留在知识组织、问答、检索和工艺重用层面。

### 1.3 不足与本文切入点

现有研究不足主要体现在：

1. 图谱多服务于知识管理、问答或工艺检索，较少为后续装配序列生成和工步资源决策设计统一字段；
2. 多数图谱只表达工艺知识，资源能力、夹持器、夹具、特殊设备和证据来源表达不足；
3. LLM 抽取带来效率提升，但若缺少本体约束、来源定位和人工校核，难以保证可靠性；
4. 历史自动化装配案例往往没有被结构化为可复用案例知识。

本文拟从“面向工步规划的知识复用”出发，把产品、工艺、资源、案例和证据统一建模，为装配序列生成和工步资源决策提供同一知识底座。

## 2. 装配序列规划与知识驱动序列生成

### 2.1 主流研究脉络

装配序列规划是连接产品设计与制造执行的核心环节。传统研究大致包括：

1. **几何推理方法**：根据可分离性、干涉关系和方向阻挡图推导装配或拆卸顺序；
2. **图论方法**：将装配约束表示为优先关系图、连接关系图或割集，再求解可行拓扑序；
3. **元启发式优化**：利用遗传算法、蚁群、粒子群等搜索满足目标函数的近优装配序列；
4. **学习方法**：利用强化学习、图神经网络等从装配关系图中学习排序策略；
5. **知识图谱驱动方法**：利用 KG 中的装配关系和工艺约束压缩搜索空间；
6. **LLM/Agent 方法**：利用大模型语义理解与多智能体任务分解能力生成或辅助生成工艺路线。

### 2.2 代表性研究

Xie 等提出基于 LLM 多智能体协同的机加工艺路线快速生成方法，将任务分为特征识别、特征排序、工艺链和资源选择、路线合并优化四个子任务，并引入知识图谱和 TOPSIS 评价方法。这说明在制造规划中，较成熟的 LLM/Agent 论文并不是只用模型生成结果，而是结合专用工具、知识库、子任务分解和决策评价机制。该文与本文最接近，但对象是机加工艺路线，而非装配序列和工步级语义。

AssemMate 面向机器人装配辅助任务，从装配文档和三维模型构建装配知识图谱，并以图结构增强 LLM 完成装配问答和任务规划。[AssemMate, arXiv](https://arxiv.org/html/2509.11617v2) 该工作证明结构化图知识能提升装配任务中的 LLM 推理质量，但其主要目标是问答和任务辅助，不是生成带工艺语义与步骤级证据追踪的装配序列。

Shu 等提出基于图强化学习的 Subassembly to Assembly 装配序列规划方法，用学习策略解决子装配到总装的排序问题。该类方法说明学习模型可以提高序列搜索能力，但其输出多聚焦于顺序或动作层，通常缺少工艺语义、资源需求和可追溯经验证据。

### 2.3 不足与本文切入点

现有装配序列研究的不足：

1. 传统几何/图论/优化方法多输出顺序与方向，工艺语义不足；
2. 学习方法依赖数据和奖励设计，可解释性和证据可追溯性较弱；
3. KG 驱动方法多将图谱作为静态优先约束，缺少运行时几何和视觉证据验证；
4. LLM/Agent 方法如果缺少约束图、证据准入和消融评价，容易被认为是启发式生成。

本文的切入点是：

> 用 KG 提供工艺先验，用 STEP/视觉提供运行时证据，用多智能体完成检索和取证，用约束图和拓扑排序完成序列推导，用证据准入规则控制输出可信度。

## 3. 装配资源、夹持器、夹具与工步规划

### 3.1 主流研究脉络

装配序列生成之后，还需要将工艺意图实例化为具体工步。这涉及：

1. 装配设备与工艺装备选择；
2. 夹持器/末端执行器选择；
3. 夹具/定位方式选择；
4. 工步模板和工艺参数确定；
5. 特殊工艺资源调用。

该领域常见方法包括：

- 多准则决策：AHP、TOPSIS、VIKOR、DEMATEL、熵权法等；
- 资源能力建模：将设备、工具、夹持器、夹具能力参数化；
- 可重构装配系统优化：联合考虑设备选择、序列规划、资源配置和生产目标；
- 知识驱动资源配置：用规则、案例或知识图谱推荐资源；
- 任务导向抓取/夹持器选择：根据装配任务而非通用抓取质量选择末端执行器。

### 3.2 代表性研究

可重构装配系统研究通常将设备选择和装配序列规划联合建模。例如，设备选型与序列规划耦合的研究说明资源配置会影响装配顺序和执行效率，但这类问题通常需要预设候选设备集、生产目标、成本和节拍，属于较高层级的系统配置优化。

Youssef 和 ElMaraghy 关于可重构制造系统配置选择的研究说明，制造系统配置选择涉及机器选择、配置结构、产能和成本等多目标优化，问题规模明显大于单个硕士论文中的工步决策。[RMS configuration selection](https://link.springer.com/article/10.1007/s10696-007-9020-x)

夹持器选择方面，Xu 等提出面向装配任务的结构化夹持器选择与设计方法，说明装配夹持器选择需要考虑 CAD 几何、装配约束和碰撞等因素，而不能只按通用抓取质量评价。[Xu et al., 2021](https://arxiv.org/abs/2003.04087)

在知识复用和夹具设计方面，既有研究从知识库、案例库、规则推理逐步发展到知识图谱和数据驱动优化。MA-APKG 中的工具设备资源层和历史案例层也说明，装配资源与历史案例应被纳入知识模型，而不是在工步规划阶段临时手工输入。

### 3.3 不足与本文切入点

现有研究不足：

1. 设备、夹持器、夹具选择常被分别研究，缺少统一上游工艺语义驱动；
2. MCDM 方法常依赖人工候选集和专家权重，难以解释候选如何从产品设计信息中自动产生；
3. 夹持器和抓取研究多关注几何抓取，较少考虑装配工艺原语、历史案例和证据追溯；
4. 夹具研究常聚焦结构设计或布局优化，较少服务于工步级资源决策；
5. LLM 直接选择工具/夹具缺少工程约束，专家认可度不足。

本文的切入点：

> 将第 3 章输出的工艺语义作为上游驱动，结合第 2 章中的资源库、案例库和规则约束，先生成候选资源，再进行硬约束过滤和多准则排序。Agent 只做查询与编排，不做唯一决策依据。

## 4. 双臂柔性装配单元与布局边界

### 4.1 主流研究脉络

双臂机器人装配具有更强的协同操作能力，可完成扶持-装配、夹持-紧固、定位-检测等任务。但双臂也带来新的复杂性：

1. 双臂基座布局；
2. 工作空间重叠；
3. 双臂互碰；
4. 工具架与夹具布置；
5. 任务分配；
6. 工具快换；
7. 夹具/工装设计；
8. 运动规划与同步控制。

因此，如果论文同时研究双臂布局优化、工具快换设计、夹具结构设计和轨迹规划，范围会明显过大。

### 4.2 固定双臂方案的合理性

本文建议将双臂柔性装配单元作为固定平台：

- Franka 机械臂数量、基座位置固定；
- 工作台和工具区固定；
- 夹具安装区固定；
- 可选资源库固定；
- 研究对象是该固定平台上的工步级资源决策。

这样可以避免研究退化为“柔性装配线配置”或“工作站布局优化”，同时保留柔性装配单元的实际工程场景。

### 4.3 本文可写的双臂装配任务

适合纳入本文的任务：

- 主臂操作、辅臂扶持；
- 一臂夹持零件，另一臂执行紧固/点胶/检测；
- 双臂协作定位较大零件；
- 根据工步选择夹持器、工具、夹具和特殊设备；
- 对不可执行工步输出缺失项或外部设备需求。

不建议纳入本文的任务：

- 双臂基座位置优化；
- 工具快换机构详细机械设计；
- 夹具结构详细设计；
- 完整碰撞自由轨迹生成；
- 生产线节拍和产能优化。

## 5. 锂电池模组装配与特殊工艺处理

### 5.1 案例合理性

锂电池模组作为案例是合理的。其装配过程通常包含多类典型装配工艺：

- 电芯堆叠/排列；
- 端板、侧板、盖板定位；
- 压紧或预紧；
- 涂胶、点胶或导热材料施加；
- 螺钉紧固；
- 汇流排连接；
- 激光焊接或其他连接工艺；
- 电性能和外观检测。

这些工艺同时包含普通装配、资源选择和特殊工艺设备调用，适合验证本文“工艺知识复用 → 序列生成 → 工步资源决策”的完整链条。KUKA 等工业资料也将电池生产中的电芯处理、模组装配、焊接、粘接和测试等作为关键自动化环节。[KUKA battery production](https://www.kuka.com/en-us/industries/battery-production)

### 5.2 特殊工艺处理原则

特殊工艺不应由 Agent 猜测，也不应强行由 Franka 完成。建议分三类：

1. **双臂可直接执行**：抓取、放置、插装、扶持、简单紧固、简单检测；
2. **双臂配合专用工具执行**：点胶、电批紧固、压紧、视觉检测；
3. **外部专用设备执行**：激光焊接、热压、电性能测试等。

第三类应建模为 `ExternalProcessStation` 或 `SpecialTool`，工步规划只输出“需要该资源”和其前后条件。

### 5.3 逻辑风险与修正

可能的逻辑风险：

1. 仅用锂电池案例，容易被质疑规则写死；
2. 由工厂模式迁移到双臂柔性单元，可能存在资源能力不一致；
3. 特殊工艺设备不是双臂本体能力，不能宣称机器人自动完成；
4. 如果所有判断都由 Agent 生成，理论性不足。

修正方式：

1. 将锂电池定位为主案例和知识来源，而非唯一适用对象；
2. 通过本体、工步模板和资源库抽象出通用字段；
3. 特殊工艺作为外部资源调用需求；
4. 至少增加一个小型机械装配案例作为补充验证；
5. 决策环节采用硬约束过滤和 MCDM 排序，避免纯 Agent 决策。

## 6. LLM/Agent 方法的研究定位

### 6.1 现有 LLM/Agent 研究的共同趋势

制造和机器人领域的 LLM/Agent 研究已经形成一个共识：

> LLM 适合语义分解、检索、工具调用、候选生成和解释，但不应单独承担物理可行性、工艺约束和资源可行性判断。

Xie 等制造工艺路线生成工作使用多智能体、STP 解析工具、知识图谱查询和 TOPSIS 评价，而不是简单让 LLM 直接输出工艺路线。AssemMate 使用图结构知识增强 LLM，而不是纯文本 RAG。机器人任务规划领域的 SayCan、Code-as-Policies、ProgPrompt、LLM3、AutoTAMP 等工作也强调将 LLM 与价值函数、工具、TAMP 求解器或失败反馈结合。

### 6.2 本文如何避免方法单薄

本文中 LLM/Agent 的角色应被限定为：

1. 从非结构化资料中辅助抽取候选知识；
2. 将工艺需求转化为 KG 查询；
3. 调用 STEP/视觉工具获取证据；
4. 对候选结果进行解释和组织；
5. 在证据不足时报告缺失项。

真正的方法支柱是：

- 本体与知识图谱；
- 案例复用；
- 约束图与拓扑排序；
- 证据分层与准入函数；
- 工步模板；
- 资源能力约束；
- 多准则决策。

## 7. 建议写入绪论的研究缺口

可写为：

> 现有研究已在装配工艺知识图谱构建、装配序列规划和机器人任务规划等方面取得进展，但仍存在三方面不足。首先，装配工艺知识图谱多面向检索、问答或知识管理，较少将产品、工艺、资源、案例和证据统一组织为可直接支撑工步规划的知识底座。其次，装配序列规划方法多关注顺序、方向或位姿，缺少与下游工具、夹持器、夹具选择直接关联的步骤级工艺语义及证据追溯机制。最后，装配资源选择、夹持器选择和夹具选择往往作为独立问题处理，依赖人工候选集和专家经验，尚未形成由装配语义驱动、案例知识复用、资源约束过滤和多准则评价相结合的工步级决策方法。针对上述问题，本文面向固定双臂柔性装配单元，研究可追溯装配工艺知识复用、证据闭环装配序列生成和工步级资源决策方法。

## 8. 建议重点引用方向

1. KG 与工艺规划综述：Xiao et al. 2023；
2. LLM + 多智能体制造路线生成：Xie et al. 2025；
3. 装配 KG + LLM 辅助：AssemMate；
4. 复杂装配工艺 KG 构建：MA-APKG；
5. 可重构制造/装配系统配置：Youssef and ElMaraghy；清华可重构柔性装配相关工作；
6. 夹持器选择：Xu et al. 2021；
7. 资源选择/MCDM：AHP、TOPSIS、VIKOR 相关设备选型综述；
8. LLM/TAMP/机器人任务规划：SayCan、Code-as-Policies、ProgPrompt、LLM3、AutoTAMP；
9. 电池模组自动化装配和特殊工艺：工业资料与电池装配研究资料。
