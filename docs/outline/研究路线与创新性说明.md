# 研究路线与创新性说明

## 1. 对当前困惑的直接回答

### 1.1 “每一步都用 LLM/Agent，会不会太单一？”

会有这个风险。解决方式不是不用 LLM/Agent，而是把 LLM/Agent 放到正确位置。

本文不应写成：

```text
第 2 章：Agent 构建知识图谱
第 3 章：Agent 生成装配序列
第 4 章：Agent 选择工具和夹具
```

这样专家会认为方法单薄、不可控、缺少机械与制造学科的理论支撑。

建议写成：

```text
第 2 章：本体 + 知识图谱 + 案例复用 + 规则约束
第 3 章：KG 先验 + 证据准入 + 约束图 + 拓扑排序 + Agent 取证
第 4 章：工步模板 + 资源硬约束过滤 + 案例相似度 + MCDM 排序 + Agent 编排
```

这样 LLM/Agent 是能力增强层，而不是唯一方法。

### 1.2 “固定双臂是否会带来新问题？”

会，但可以通过边界控制解决。

如果研究“双臂如何布局、工作台如何设计、工具架如何布置、夹具如何设计、轨迹如何规划”，论文会变成柔性装配工作站设计与优化，范围过大。

建议声明：

```text
双 Franka 装配单元为给定实验平台。
本文不优化双臂布局，不设计真实夹具结构，不生成完整轨迹。
本文研究该固定平台下，如何根据工艺语义和资源库生成工步级资源决策方案。
```

### 1.3 “复用工厂经验，让柔性装配单元正确装配机械产品，是否有说服力？”

有，但需要把“复用”说清楚。不是把工厂流程原样搬到 Franka，而是：

1. 从工厂自动化装配案例中抽取工艺知识；
2. 抽象为工艺原语、资源能力、工步模板和约束；
3. 根据固定双臂单元资源库重新匹配可执行方案；
4. 对不可迁移的特殊工艺输出外部资源或缺失项；
5. 由专家或工厂案例验证方案合理性。

这样逻辑是成立的。

## 2. 本文的研究目的

本文的目的不是证明 LLM 能自动装配产品，而是证明：

> 已有工厂装配经验可以通过可追溯知识图谱和案例复用机制转化为可计算知识，并在固定柔性装配单元中支撑装配序列生成和工步级资源决策。

换句话说，本文要回答三件事：

1. 工厂经验如何结构化？
2. 结构化经验如何参与装配序列规划？
3. 规划结果如何转成柔性装配单元能理解的工步资源方案？

## 3. 本文的主要研究内容

### 3.1 研究内容一：面向工步规划的装配工艺知识复用

核心任务：

- 建立产品-工艺-资源-证据模型；
- 构建装配工艺知识图谱；
- 将自动化装配案例转化为可复用案例单元；
- 建立工步模板和资源能力库；
- 保留来源证据。

本部分回答“知识如何复用”。

### 3.2 研究内容二：知识图谱先验与多智能体证据闭环装配序列生成

核心任务：

- 利用 KG 提供工艺先验；
- 利用 STEP 几何和视觉证据验证先验；
- 通过 APO/KRA/PFA/VES 多智能体完成取证和编排；
- 构建约束图并拓扑排序；
- 输出带工艺语义和证据链的装配序列。

本部分回答“如何生成可信装配序列”。

### 3.3 研究内容三：固定双臂装配单元下的工步级资源决策

核心任务：

- 固定双 Franka 单元和资源库；
- 将装配步骤映射为工步模板；
- 生成工具、夹持器、夹具和特殊设备候选；
- 用硬约束过滤不可行候选；
- 用 MCDM 和案例相似度排序；
- 输出工步级方案。

本部分回答“如何从序列走向工步规划”。

## 4. 创新性在哪里

### 4.1 创新点一：面向工步规划的知识复用模型

已有 KG 研究多服务于知识检索、问答或静态工艺管理。本文将自动化装配案例、资源能力、工步模板和证据来源纳入同一知识模型，使知识图谱直接面向装配序列和工步资源决策。

创新性表述：

> 提出产品-工艺-资源-证据一体化的装配工艺知识表示模型，将工厂自动化装配案例转化为可追溯、可检索、可约束的工步规划知识。

### 4.2 创新点二：从“顺序生成”扩展到“工艺语义序列”

传统 ASP 多输出零件顺序和装配方向。本文输出：

```text
零件 + 工艺原语 + 基座/移动件角色 + 配合面 + 姿态要求 + 工装需求 + 证据
```

这使第 3 章结果可以直接驱动第 4 章资源决策。

创新性表述：

> 提出带工艺语义与步骤级证据追踪的装配序列表示方法，使装配序列成为连接知识复用与工步资源决策的中间表示。

### 4.3 创新点三：证据闭环抑制 LLM/Agent 幻觉

本文不让 Agent 直接生成最终结果，而是要求每个工艺判断进入证据准入：

- KG/案例提供工艺依据；
- STEP 提供几何事实；
- 视觉证据提供可复核图像；
- Agent 推断只能作为待验证结论；
- 证据不足则输出缺失项。

创新性表述：

> 构建知识图谱先验与运行时几何/视觉证据协同的多智能体证据闭环，将 LLM/Agent 的开放式生成约束为可验证、可追溯的装配推断。

### 4.4 创新点四：面向固定双臂单元的工步级资源决策

现有资源选择、夹持器选择、夹具选择往往分散研究。本文用第 3 章的工艺语义统一驱动资源决策：

```text
工艺语义 → 工步模板 → 候选资源 → 约束过滤 → MCDM 排序 → 工步方案
```

创新性表述：

> 提出由装配工艺语义驱动的工步级资源决策方法，将工具、夹持器、夹具和特殊工艺资源选择统一到固定双臂柔性装配单元中。

## 5. 理论支撑如何安排

### 5.1 第 2 章理论支撑

- 本体论；
- 知识图谱；
- 案例推理；
- 规则推理；
- 来源追踪。

### 5.2 第 3 章理论支撑

- 约束图；
- 拓扑排序；
- 证据分层；
- 证据准入函数；
- 多智能体任务分解。

### 5.3 第 4 章理论支撑

- 工步模板；
- 资源能力模型；
- 硬约束过滤；
- 案例相似度；
- 多准则决策，如 TOPSIS 或 AHP-TOPSIS。

## 6. 双臂装配单元建议设定

### 6.1 固定平台

建议设置：

- 左右两台 Franka；
- 中央工作台；
- 一个通用定位夹具安装区；
- 工具/夹持器存放区；
- 特殊工艺设备接口区；
- 上位控制系统和知识决策系统。

### 6.2 资源库

建议资源库包括：

```text
Gripper: parallel gripper, vacuum gripper, soft gripper
Tool: screwdriver, dispensing tool, pressing tool, camera
Fixture: positioning fixture, support fixture, clamping fixture
ExternalStation: laser welding, heat pressing, electrical testing
```

### 6.3 工步输出

每个工步输出：

```text
{
  step_id,
  action_template,
  left_arm_role,
  right_arm_role,
  gripper,
  tool,
  fixture,
  external_station,
  precondition,
  postcondition,
  evidence,
  missing_items
}
```

## 7. 锂电池案例的逻辑说明

### 7.1 为什么可以用锂电池

锂电池模组装配包含多类典型工艺：

- 堆叠；
- 定位；
- 压紧；
- 涂胶；
- 紧固；
- 焊接；
- 检测。

这些工艺足以覆盖“普通工步 + 资源选择 + 特殊工艺”的研究需求。

### 7.2 如何避免“只为锂电池写规则”

建议采取：

1. 把锂电池作为主案例；
2. 把工艺抽象为通用工艺原语；
3. 把资源抽象为能力模型；
4. 用一个小型机械装配体做补充验证；
5. 明确方法适用条件和边界。

### 7.3 特殊工艺如何处理

特殊工艺分为：

| 类型 | 处理方式 |
|---|---|
| 双臂可完成 | 输出双臂工步 |
| 需要专用工具 | 输出工具资源与参数 |
| 需要外部设备 | 输出外部工艺站调用需求 |
| 证据不足 | 输出缺失项与人工复核 |

## 8. 推荐论文贡献表述

建议最终写为：

1. 面向工步规划需求，建立产品-工艺-资源-证据一体化的装配工艺知识模型，支持工厂自动化装配经验的结构化复用；
2. 提出知识图谱先验与多智能体证据闭环相结合的装配序列生成方法，实现带工艺语义和步骤级证据追踪的序列输出；
3. 提出面向固定双臂柔性装配单元的工步级资源决策方法，融合工步模板、资源能力约束、案例相似度与多准则评价，实现工具、夹持器、夹具和特殊工艺资源的协同选择；
4. 以锂电池模组自动化装配案例为主要对象构建原型系统，验证工艺知识复用、序列生成和工步资源决策的可行性。

## 9. 最终一句话定位

> 本文不是研究“LLM 如何替代工艺员”，也不是研究“如何完整设计双臂产线”，而是研究如何把已有工厂装配经验转化为可追溯知识，并在固定双臂柔性装配单元中生成可校核的装配序列与工步级资源决策方案。
